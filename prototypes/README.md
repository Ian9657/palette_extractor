# Prototypes

Design steps on the way from the classic page to the magazine edition. Kept for reference; the live site does not link to them.

| File | Idea |
| --- | --- |
| `1-register.html` | The page as an accession register: each image is deposited, catalogued and filed. Colour plates stacked under the sheet. |
| `2-cyber.html` | Night-city skin: dark void, HUD rail, misregistered title, a scanner lens that shows the page's neon negative. |
| `3-zine.html` | First attempt to fuse the beige zine with the cyber system. Rejected: no magazine structure, cyber elements felt pasted on. |

They share `style.css`, `register.css/js` and the colour logic with the main site, so open them through a local server from the project root:

```sh
python3 -m http.server
# http://localhost:8000/prototypes/1-register.html
```
